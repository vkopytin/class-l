Image artwork collected from the existing resource sets, grouped by watch display resolution. Fonts are excluded from this collection. Original filenames and file contents are preserved. Existing background.png files are retained.

The 260x260 sets have identical overlapping files, so each is stored once.

No matching resource artwork is currently available for 218x218, 360x360, 390x390, or 416x416. Those folders retain their existing contents; no artwork has been resized or generated.

This is an artwork collection. Resource XML, JSON, settings, source mappings, and original resource files remain in their existing locations.
